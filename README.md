# LocalMind OS

Публичная Linux-система для локального ИИ с приоритетом AMD Radeon.

> Статус: ранняя фаза (E0/E1). Репозиторий содержит каркас, документацию
> и начальный аппаратный детектор. Никаких гарантий совместимости пока нет —
> см. `docs/COMPATIBILITY.md`.

## Принципы проекта

1. Максимально использовать существующие проверенные проекты (upstream-first).
2. Не переписывать upstream-компоненты без необходимости.
3. Не изменять лицензии, авторство и брендинг сторонних проектов.
4. Не заявлять о совместимости без проверяемых доказательств.
5. **Не допускать незаметного перехода с GPU на CPU** (см. `docs/POLICY.md`).
6. Полноценное управление через CLI; GUI — дополнительный интерфейс.
7. Никаких разрушительных действий без явного разрешения.
8. Системные пакеты и настройки ОС не меняются без отдельного разрешения.

## Быстрый старт (только чтение оборудования, без установки чего-либо)

```bash
./localmind-detect --json > report.json   # отчёт об оборудовании (schema 0.2.0)
./localmind-detect                        # человекочитаемый вывод: CPU/RAM/GPU
./localmind-detect --doctor               # первичная диагностика GPU
```

Детектор работает только на чтение (`lspci`, `/sys`, `/dev`) и ничего не устанавливает.

## Лицензии и товарные знаки

- Код этого репозитория — MIT (см. `LICENSE`).
- Ubuntu — товарный знак Canonical Ltd. LocalMind OS не аффилирован с Canonical.
- AMD, Radeon, ROCm — товарные знаки Advanced Micro Devices.
- Ollama, llama.cpp, LACT, Vulkan — свойства соответствующих проектов/компаний.

Подсистемы, устанавливаемые из upstream (llama.cpp, Ollama, ROCm, LACT),
сохраняют свои лицензии и бренды; LocalMind OS только интегрирует их.
